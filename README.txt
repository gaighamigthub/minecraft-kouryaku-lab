# マイクラ攻略ラボ

スマホ対応の非公式Minecraft攻略サイトの初期版です。

## 含まれるもの
- スマホ最優先レスポンシブUI
- トップページ
- 人気記事・最新記事
- カテゴリ検索
- キーワード検索
- 個別記事ページ
- 関連記事
- About / Privacy / Contact
- 広告スペース（AdSense承認後にコードを設置する想定）
- robots.txt / sitemap.xml

## 公開前に必ず変更するもの
1. `YOUR-DOMAIN.example` を実際のドメインへ変更
2. お問い合わせ手段を設定
3. プライバシーポリシーを実際の広告・解析・フォームに合わせて更新
4. 自分で確認・編集したオリジナル記事を増やす
5. 利用する画像・素材の権利を確認
6. 広告サービスの最新ポリシーを確認し、承認後に広告コードを設置

このサイトはMinecraftの非公式ファンサイトです。Mojang Studios / Microsoftとは提携・承認されていません。
